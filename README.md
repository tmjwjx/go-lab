# go-lab

Go 语言学习练习场(2023~2025):按主题的代码练习与实验。

- 主题目录:`goroutine` `channel` `redis` `etcd` `gin` `gorm` `websocket` `eino` `langchaingo` `mcp` `socks5` `protoc` `reflect` `mysql` `zap` `file` `json` `time` `util` 等
- `labs/`:独立小项目练习(gin-study · websocket · watermelon · find-different · gorm-study · eventbus)

每个目录即一个主题的实验代码,可直接 `go run`。
